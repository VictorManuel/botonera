# Seguridad

## Versiones soportadas

La rama `main` es la única versión que recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No publiques vulnerabilidades explotables en un issue abierto. Usá la opción **Report a vulnerability** de la pestaña **Security** del repositorio para enviar un reporte privado con:

- descripción e impacto;
- pasos mínimos para reproducirla;
- navegador y sistema operativo;
- una propuesta de solución, si la tenés.

No incluyas audios personales, respaldos `.botonera.json` ni otros datos privados en el reporte. Se confirmará la recepción y se coordinará la divulgación después de tener una corrección disponible.
